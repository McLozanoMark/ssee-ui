# Local Demo Index

The local demo entry point is `index.html`. Every active requirement demo must
be registered there and must provide a visible return path to the index.

This index is the local equivalent of the planned Figma requirement index. It
will be updated whenever a new requirement demo is added. The official Figma
version will be assembled later from the approved specs, prototype markdowns,
and design-system rules; the local index does not replace that deliverable.

Requirements without an implemented demo must link to a clearly marked pending
screen instead of presenting a broken link or an unapproved flow.
